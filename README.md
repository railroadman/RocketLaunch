# FLIGHT · RocketLaunch

**От стартовой площадки до орбиты — и обратно.**

## О проекте

RocketLaunch объединяет кинематографическую визуализацию полёта и расчётную телеметрию. Можно смотреть миссию с автоматической камерой, следить за каждой ступенью, свободно осматривать сцену и переходить к любому событию на временной шкале.

Полный автоматический показ занимает **4 минуты 50 секунд**: **4:30** на запуск, возвращение и выпуск спутников, затем **20 секунд** на сход второй ступени с орбиты. Время миссии и время показа отображаются отдельно.

> Это учебная расчётная миссия с приближёнными параметрами. Она не воспроизводит конкретный запуск и не использует реальную телеметрию SpaceX.

## Возможности

- **Полный сценарий полёта.** Обратный отсчёт, старт, разделение ступеней, сброс обтекателя, пересечение линии Кармана, возвращение и посадка первой ступени, выпуск восьми спутников и утилизация второй ступени.
- **Детальная 3D-сцена.** Девять двигателей Merlin, решётчатые рули, раскрывающиеся опоры, стартовый комплекс и наземная посадочная площадка.
- **Атмосфера и эффекты.** Объёмные факел и дым, пыль, расширение выхлопа с высотой, закатное освещение, звёздное небо и кривизна Земли.
- **Камера и воспроизведение.** Автоматическая режиссура, свободный обзор, пауза, перемотка и ускорение до 25×. Обе ступени продолжают движение независимо от выбранного ракурса.
- **Телеметрия и аналитика.** Высота, скорость, топливо, скоростной напор, давление, графики, журнал событий, параметры модели и экспорт CSV.
- **Звук.** Синтезированный шум двигателей и голосовой отсчёт; звук активируется после нажатия кнопки старта.
- **Шесть языков.** Русский, English, Українська, Deutsch, Français и Español. Смена языка сохраняет состояние миссии и настройки.
- **Настройки качества.** HIGH / MEDIUM / LOW для выбора детализации эффектов и разрешения рендера.

Модели, текстуры и шрифты не требуют обязательных сетевых запросов во время работы приложения.

## Быстрый старт

Понадобятся **Node.js 22.12+**, npm и современный браузер с **WebGL 2**. Проект ориентирован на ПК; для высоких настроек качества предпочтительна отдельная видеокарта.

В каталоге проекта выполните:

```sh
npm install --legacy-peer-deps
npm run dev
```

Откройте адрес, указанный Vite в терминале — обычно [http://127.0.0.1:5173/](http://127.0.0.1:5173/). Дождитесь расчёта миссии и нажмите **«Начать миссию»**.

### Сборка для публикации

```sh
npm run build
npm run preview
```

Готовые файлы находятся в `dist/`. Их можно разместить на статическом хостинге. Для локального просмотра используйте адрес из вывода `npm run preview`.

Приложению нужен HTTP-сервер: открытие `index.html` через `file://` не поддерживается из-за модульного Worker и загрузки ресурсов.

## Управление

| Элемент | Действие |
| :--- | :--- |
| Старт / пауза | Запустить или приостановить миссию |
| Круговая стрелка | Сбросить миссию и восстановить автоматическую камеру |
| Шкала времени и отметки событий | Перейти к выбранному моменту полёта |
| Темп | Автоматический показ или скорость 1× / 2× / 5× / 10× / 25× |
| Режиссура | Автоматически выбирать аппарат и ракурс |
| Ступень 1 / ступень 2 | Следить за выбранной ступенью после разделения |
| Автокамера | Переключить автоматическую камеру и свободный обзор |
| Мышь / колесо | Вращать камеру и менять масштаб в свободном обзоре |
| HIGH / MEDIUM / LOW | Изменить качество графики |
| Данные и модель | Открыть графики, таблицы, события, допущения и источники |
| CSV | Скачать расчётную телеметрию обеих ступеней |
| Выбор языка | Переключить язык интерфейса |
| `Пробел` | Пауза / продолжение |
| `←` / `→` | Перемотка на 10 секунд назад / вперёд |
| `R` | Сброс миссии |

Клавиатурные команды работают, когда фокус находится вне элементов управления. Время **T− / T+** относится к миссии; время ускоренного показа указано отдельно. Перемотка восстанавливает состояние ступеней, обтекателя, спутников и журнала.

## Физическая модель

Миссия рассчитывается в **Web Worker**, чтобы не блокировать интерфейс. Основной полёт использует интегрирование **RK4 с шагом 0,02 с**. На отдельных участках свободного полёта при утилизации второй ступени применяется шаг 0,2 с.

Модель учитывает:

- гравитацию сферической Земли и её вращение;
- совместное вращение атмосферы, изменение её плотности, температуры и давления с высотой;
- тягу, удельный импульс, расход топлива и аэродинамическое сопротивление;
- отдельные траектории двух ступеней и восьми спутников;
- управление возвращением и посадкой по расчётному состоянию аппарата.

Основные соотношения:

```text
q = ρ · v_air² / 2                  скоростной напор
D = Cd · q · A                     сопротивление
a = (T_vector − D_vector) / m
    − μ · r / |r|³                 ускорение
ṁ = −T / (Isp · g₀)                расход топлива
```

Первая ступень сохраняет рассчитанную точку касания площадки. После отделения спутники получают небольшие импульсы и движутся по собственным траекториям. Их дальнейший подъём электрическими двигателями на рабочую орбиту не моделируется.

Приближённые результаты текущей конфигурации:

| Завершение разгона второй ступени | T+08:01 |

### Сход второй ступени

После выпуска спутников тормозной импульс снижает перигей примерно до **−60 км**. Ступень входит в атмосферу, нагревается и разрушается; фрагменты падают в Индийский океан. Спутники при этом остаются на орбите.

Траектория учитывает гравитацию и сопротивление. Начало свечения на 120 км, разрушение на 70 км и вид фрагментов — условная визуализация. После разрушения используется одна опорная траектория с приближённым сопротивлением.

### Допущения

Ориентация задаётся программой управления. Полная вращательная динамика, ветер, аэродинамическая работа рулей, CFD и тепловой расчёт разрушения отсутствуют. Массы, коэффициенты сопротивления, удельный импульс и дросселирование заданы приближённо; посадочный импульс длиннее типичного реального.

Космодром условный, по мотивам прибрежной Флориды. Дым, выхлоп, облака, раскрытие батарей спутников и работа камеры художественно интерпретированы. Экспорт видео не входит в текущую версию.

### Проверки

Базовая проверка проекта:

```sh
npm run check
npm test
npm run build
```

Тесты охватывают физику атмосферы и орбит, разделение ступеней, посадку, траектории спутников, сход второй ступени, паузу и перемотку. Проверки локализации контролируют словари, подстановки, выбор языка и работу без доступа к localStorage.

Для браузерных проверок установите Chromium и запустите сервер:

```sh
npx playwright install chromium
npm run dev
```

В отдельном терминале:

```sh
npm run test:e2e
npm run test:landing-earth
```

По умолчанию проверки используют `http://127.0.0.1:5173/`. Для другого адреса задайте `BASE_URL`. Например, в PowerShell:

```powershell
$env:BASE_URL = "http://127.0.0.1:4173/"
npm run test:e2e
```

Браузерные скрипты ориентированы на Windows и используют локальный кэш Chromium. Снимки и выгруженные данные сохраняются в `artifacts/`; каталог исключён из Git. Проверки в программном WebGL подтверждают функциональность, а частота кадров зависит от оборудования и выбранного качества.

### Локализация

Язык выбирается по сохранённому значению `flight.lang` в localStorage, затем по предпочтениям браузера. Резервный язык — русский. Голосовой отсчёт остаётся русским и зависит от доступных системных голосов.

Инструкции по переводам и добавлению языков: [src/i18n/README.md](src/i18n/README.md).
